# Wayfare Travel Booking Platform

Frontend travel booking platform for flights, hotels, and cabs.

## Features
- Login
- Flights, hotels, and cabs search
- Travel option comparison
- Booking checkout and payment method selection
- Booking confirmation
- Itinerary management
- Travel alerts
- Trip confirmation PDF generation

## Run
Open `pages/login.html` first for the login flow, or `index.html` for the main page.

## Structure
- `pages/` HTML pages
- `css/` stylesheets
- `js/` JavaScript behavior
- `data/` travel data
- `assets/` project assets
- `docs/` documentation

This is a restructuring of the existing frontend code; UI and behavior are preserved.
